# JasperReports Learning Guide

A practical, step-by-step learning resource for beginners who want to learn JasperReports and build professional reports using Jaspersoft Studio.

## About This Repository

This repository covers SQL fundamentals, JasperReports concepts, database integration, report development, and real-world troubleshooting.

The goal is to help beginners understand the complete reporting workflow, from database preparation to generating PDF and Excel reports.

## Technologies & Tools

- JasperReports
- Jaspersoft Studio 6.20.6
- MariaDB / MySQL
- XAMPP
- phpMyAdmin
- MariaDB Connector/J
- SQL
- JRXML

## Learning Roadmap

1. SQL Fundamentals
2. JasperReports Basics
3. Database Import and Connection
4. Report Design and Development
5. Advanced Reporting
6. Troubleshooting and Best Practices

## Practical Topics

- Writing SQL queries for reports
- Importing large SQL database files
- Connecting MariaDB to Jaspersoft Studio
- Creating and configuring Data Adapters
- Designing reports using JRXML
- Working with fields, parameters, and variables
- Creating groups, summaries, and charts
- Generating PDF and Excel reports
- Handling Sinhala Unicode fonts

## Who Is This For?

- Students learning JasperReports
- Beginners in SQL and report development
- Junior Software Engineers
- Developers working with MySQL or MariaDB

## Important Note

All examples should use sample databases and non-confidential data. Do not upload company databases, customer information, credentials, or proprietary report templates.
