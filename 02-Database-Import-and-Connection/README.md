# 02 – Database Import & Connection

Learn how to import databases and connect MariaDB to Jaspersoft Studio.

## Topics

1. Database Import using phpMyAdmin
2. Large Database Import using CMD
3. Connect Database to Jaspersoft Studio

## Learning Objectives

- Create and manage databases.
- Import SQL database files.
- Handle large database import issues.
- Configure MariaDB JDBC connections.
- Test database connections in Jaspersoft Studio.

## Expected Result

A database successfully imported into MariaDB and connected to Jaspersoft Studio.
