# 03 – JasperReports Introduction

Learn the fundamental concepts and structure of JasperReports.

## Topics

1. Report Structure and Design Page
2. Fields
3. Variables
4. Parameters

## Learning Objectives

- Understand the Jaspersoft Studio interface.
- Identify report sections and bands.
- Understand how fields retrieve database data.
- Learn how variables calculate and store values.
- Understand how parameters pass values into reports.

## Expected Result

Understand the basic components of a JasperReport before creating your first report.
