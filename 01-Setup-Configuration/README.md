# 01 – Setup & Configuration

Prepare your computer for JasperReports development.

## Learning Objectives

By the end of this section, you will be able to:

- Download and launch Jaspersoft Studio.
- Install and configure XAMPP.
- Understand Apache, MariaDB and phpMyAdmin.
- Download and prepare MariaDB Connector/J.
- Verify that your development environment is ready.

## Required Software

Software --------------------- ---------->   Purpose 

| Jaspersoft Studio 6.20.6  ------------->   Design and develop reports |
| XAMPP---------------------------------->   Local development environment |
| Apache -------------------------------->   Web server for phpMyAdmin |
| MariaDB ------------------------------->   Database server |
| phpMyAdmin ---------------------------->   Manage databases through a browser |
| MariaDB ------------------------------->   Connector/J  JDBC driver for JasperReports |

## Setup Checklist

- [ ] Jaspersoft Studio downloaded and launched.
- [ ] XAMPP installed.
- [ ] Apache service running.
- [ ] MariaDB service running.
- [ ] phpMyAdmin accessible.
- [ ] MariaDB Connector/J downloaded.

## Expected Result

A working local environment ready for database import and JasperReports development.
