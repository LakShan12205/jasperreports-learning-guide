# Download Jaspersoft Studio 6.20.6

## 1. Overview

Jaspersoft Studio is an Eclipse-based report designer used to create and edit JasperReports.

## 2. Download

1. Open the Jaspersoft Studio download page or trusted version archive.
2. Select **Jaspersoft Studio 6.20.6 – Windows 64-bit**.
3. Download the ZIP package.
4. Extract the ZIP file to a suitable location.

> Note: Always verify the download source. Older versions may be available through archived or third-party download pages.

## 3. Launch Jaspersoft Studio

1. Open the extracted folder.
2. Locate the Jaspersoft Studio executable.
3. Run the application.
4. Select a workspace directory.
5. Click **Launch**.

## 4. Workspace

A workspace is the location where Jaspersoft Studio stores your projects and related configuration.

Example: D:\JasperReports-Workspace


## 5. Verify Installation

- [ ] Application opens successfully.
- [ ] Workspace is created.
- [ ] No startup error appears.
- [ ] You can create a new JasperReports project.

## Expected Result

Jaspersoft Studio 6.20.6 is ready to use.
