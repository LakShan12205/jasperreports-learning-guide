# Install and Configure XAMPP

## 1. Introduction

XAMPP is a local development environment that provides the tools required to run web applications and manage databases on your computer.

It includes:

- **Apache** – Web server
- **MariaDB** – Database server
- **PHP** – Server-side programming language
- **phpMyAdmin** – Web-based database management tool

In this guide, we will install and configure XAMPP for JasperReports development.

## 2. Download XAMPP

1. Visit the official Apache Friends website.
2. Select the Windows version.
3. Download the XAMPP installer.

**Official Download:** https://www.apachefriends.org/download.html

## 3. Install XAMPP

1. Run the downloaded installer.
2. Select the required components:
   - Apache
   - MySQL (MariaDB)
   - PHP
   - phpMyAdmin
3. Choose the installation directory.

Recommended location:

```text
C:\xampp
```

4. Complete the installation.

## 4. Start XAMPP Services

1. Open **XAMPP Control Panel**.
2. Click **Start** next to Apache.
3. Click **Start** next to MySQL.
4. Confirm that both services are running.

**Important:** XAMPP labels its database service as MySQL, but modern XAMPP distributions bundle MariaDB as the database server.

## 5. Open phpMyAdmin

1. Open your web browser.
2. Visit:

```text
http://localhost/phpmyadmin
```

3. The phpMyAdmin dashboard should appear.

phpMyAdmin allows you to create databases, manage tables, run SQL queries, and import database files.

## 6. Verify Installation

Check the following:

- [ ] XAMPP installed successfully.
- [ ] Apache service is running.
- [ ] MySQL / MariaDB service is running.
- [ ] phpMyAdmin opens successfully.
- [ ] Database server is accessible.

## 7. Common Problems

| Problem | Possible Solution |
|---|---|
| Apache fails to start | Check port 80 or 443 conflicts |
| MySQL fails to start | Check port 3306 conflicts |
| phpMyAdmin cannot open | Check Apache and MariaDB services |
| Database connection error | Verify database server status and credentials |

## Expected Result

XAMPP is installed and configured. Apache, MariaDB, and phpMyAdmin are ready for database management.
