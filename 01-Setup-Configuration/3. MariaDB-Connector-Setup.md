# MariaDB Connector/J Setup

## 1. Introduction

MariaDB Connector/J is a JDBC driver that allows Java applications, including Jaspersoft Studio, to connect directly to MariaDB and MySQL databases.

**Important:** MariaDB Connector/J connects Jaspersoft Studio directly to the MariaDB server. It does not connect to phpMyAdmin.

## 2. Download MariaDB Connector/J

1. Visit the official MariaDB download page.
2. Find **MariaDB Connector/J**.
3. Select a stable version compatible with your Java version.
4. Download the `.jar` file.

**Official Download:**  
https://mariadb.com/downloads/connectors/

**Version guidance:**
- Connector/J 3.5.x supports Java 8, 11, 17 and 21.
- Connector/J 4.0.x requires Java 17 or later.

For this guide, choose a compatible 3.5.x release if your Jaspersoft Studio environment uses Java 8 or Java 11.

## 3. Locate the Downloaded JAR File

After downloading, locate the file.

Example:

```text
mariadb-java-client-3.5.x.jar
```

Keep the JAR file in a permanent folder so you can easily find it when configuring Jaspersoft Studio.

Recommended location:

```text
C:\JasperReports\Drivers\
```

## 4. Configure MariaDB Connector/J in Jaspersoft Studio

1. Open **Jaspersoft Studio**.
2. Navigate to the Repository Explorer.
3. Right-click **Data Adapters**.
4. Select **Create Data Adapter**.
5. Choose **Database JDBC Connection**.
6. Enter a connection name.

Example:

```text
MariaDB_Local_Connection
```

## 5. Configure JDBC Connection Details

Enter the following settings:

| Setting | Value |
|---|---|
| JDBC Driver | MariaDB |
| JDBC Driver Class | `org.mariadb.jdbc.Driver` |
| JDBC URL | `jdbc:mariadb://localhost:3306/your_database_name` |
| Username | Your MariaDB username |
| Password | Your MariaDB password |

Replace `your_database_name` with the actual database name.

Example:

```text
jdbc:mariadb://localhost:3306/company_database
```

**Note:** The example assumes MariaDB is running locally on port `3306`. Change the host or port if your configuration is different.

## 6. Add the MariaDB Driver JAR

1. Find the **Driver Classpath** section.
2. Click **Add** or **Add JAR**.
3. Browse to the downloaded MariaDB Connector/J `.jar` file.
4. Select the file.
5. Confirm the selection.

## 7. Test the Connection

1. Make sure MariaDB is running in XAMPP.
2. Make sure the target database has already been imported.
3. Click **Test** in the Data Adapter configuration window.
4. Check the connection result.

If the connection succeeds, save the Data Adapter.

## 8. Verify the Configuration

Check the following:

- [ ] MariaDB Connector/J downloaded.
- [ ] Compatible JDBC driver version selected.
- [ ] Driver JAR added to Jaspersoft Studio.
- [ ] JDBC driver class configured.
- [ ] JDBC URL configured.
- [ ] Database username and password entered.
- [ ] Connection test successful.

## 9. Common Connection Errors

| Error | Possible Solution |
|---|---|
| No suitable driver found | Check whether the MariaDB JAR was added correctly |
| Connection refused | Start MariaDB and verify the host and port |
| Access denied | Check database username and password |
| Unknown database | Verify the database name |
| Driver class not found | Verify `org.mariadb.jdbc.Driver` |
